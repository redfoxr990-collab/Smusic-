# Smusic

مشغل موسيقى أندرويد (Kotlin + Jetpack Compose + Media3) يشغّل الأغاني من ملفات الجهاز
بتصميم Neumorphism داكن.

## طريقة الحصول على ملف APK
1) **Android Studio**: File > Open > اختر مجلد Smusic > انتظر Gradle Sync >
   Build > Build Bundle(s) / APK(s) > Build APK(s).
   الملف يكون في: app/build/outputs/apk/debug/app-debug.apk
2) **بدون برامج**: ارفع المجلد على GitHub (مستودع جديد)، ثم من تبويب Actions
   شغّل "Build APK" ونزّل الملف Smusic-apk.
